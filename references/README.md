# 사주첩경 참고자료 폴더

이 폴더의 파일은 `saju_app.py`의 `collect_references()`가 **사주 결과에 맞는 것만 골라서**
Gemini 프롬프트에 자동으로 끼워넣습니다. 파일이 없으면 그냥 조용히 건너뜁니다(에러 없음).

## 채워 넣는 방법

각 파일에 지니님이 정리하신 사주첩경 요약(또는 직접 판단 기준 노트)을 마크다운으로 넣으세요.
원문을 그대로 옮기기보다는, **판단 기준을 지니님 말로 정리**하는 걸 추천합니다
(저작권 문제도 피하고, LLM이 "인용"이 아니라 "기준"으로 활용하기도 쉬워요).

### 신살 (sinsal/) — 코드가 계산한 신살과 정확히 이름이 일치해야 로드됩니다
- `역마.md`, `도화.md`, `천을귀인.md`, `화개.md`
- 예: 역마.md 안에 "역마살이 원국에 있을 때의 이석영식 해석 기준, 대운/세운에서 만났을 때 주의점" 등

### 격국 (gyeokguk/)
- `general.md` — 격국 판단 총론 (항상 포함됨)
- `종격.md` — 신강신약 점수가 0~20점 또는 80~100점일 때만 포함됨 (극단적 신강/신약)

### 육친 (yukchin/)
- `general.md` — 육친 해석 총론 (항상 포함됨)

## 파일 하나당 권장 분량
A4 반 장~1장 정도로 압축해서 넣어주세요. 너무 길면 프롬프트 토큰이 늘어나고,
너무 짧으면 정보가 부족합니다. 항목별로 나눠 정리하신 자료가 있다면 딱 맞는 형태입니다.
